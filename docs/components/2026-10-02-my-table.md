# Component MyTable dùng chung cho các bảng admin

- Ngày: 2026-10-02
- Phạm vi: components / admin

## Mục đích
6 trang admin (khách hàng, bình luận, liên hệ, bảng giá, blog, đơn hàng) đều tự viết `<table>` với cùng class `th`/`tr` và lặp lại khối loading / empty / pagination. Gom lại thành `MyTable` để style thống nhất và code trang gọn hơn.

## Luồng xử lý
1. Trang khai báo `columns: MyTableColumn<T>[]` — mỗi cột có `key`, `title`, `align` (`left` | `center` | `right`), `className` (td), `headerClassName` (th) và `render(record, index)`.
2. Truyền `data` (đã lọc + phân trang ở client), `rowKey`, `loading`, `emptyMessage`, `pagination`.
3. `MyTable` hiển thị:
   - `loading = true` → `MyLoading`
   - `data` rỗng → `MyEmpty` với `emptyMessage`
   - còn lại → bảng + `MyPagination` (chỉ hiện khi `totalPages > 1`).

## Lưu ý
- Header (`th`) mặc định `whitespace-nowrap` cho mọi bảng.
- Cột "Thời gian" trang liên hệ nay căn giữa cả header lẫn ô (trước đó chỉ header căn giữa).
- `components/ChatMarkdown` vẫn giữ `<table>` riêng vì đó là style render markdown, không phải bảng dữ liệu.
- Còn text hardcode có sẵn từ trước ở trang khách hàng (`'Admin'`, `'Khách hàng'`, `'Hoạt động'`, `'Tạm khóa'`) — cần chuyển sang `translate()`.
